# 实验方法（与实际执行一致的论文方法短段落）

> 本段落描述配对对比实验的方法。未完成部分已明确标注。

## 设计

在同一可运行的问答系统版本上，构造 baseline 与 governed 两组配对对比。两组共用同一模型、同一参数、同一基础检索设置（Milvus 集合 CHUneng，BGE-M3 向量 + BGE-reranker 精排）、同一通用引用/数值检查与修复轮次；二者唯一差异是：governed 组在回答证据上下文中额外注入**既有的、可定位的人工校正关系记录与查询范围说明**（五条人工规则校正的储能案例演化边，及其中 ADAPTS 对应的一条正式 confirmed 记录），并保留每条记录的关系状态、方向依据、原文证据句编号与适用范围；baseline 组不读取、不注入这些记录，也不走人工谱系记录直出渲染的捷径。两组采用相同的生成路径。

## 题集与运行

题集为既有 50 题（covering 属性/性能、合成制备、表征、反应过程、机理、结构、综合、幻觉合规压力测试八类），仅提取题号、题型与题目，不使用历史分数，也不将历史分数输入回答生成。该 50 题此前曾用于调试，故本实验定位为**已有题集上的配对对比，非独立盲测**。两组均重新运行，不混用历史答案。每题记录治理模块是否实际触发、采用了哪些记录；没有相关治理记录的题目仍保留在总体结果中——因此**并非 50 题全部受到治理约束**（治理仅在问题涉及已记录的方法演化关系时触发）。

## 评价

评价维度为正确性、完整性、引用支撑、对象与条件匹配，各 0–5 分。评分前固定评分说明，使用随机顺序、隐藏组别的盲审材料与独立的组别映射。AI 评分仅作辅助初评，最终论文使用的人评分由作者另行安排确认。按完成的评分计算两组各维均值、标准差与逐题配对差值，以五分制报告分数提高或降低多少分（不表述为准确率或百分点）。实际效果可能提升、持平或下降，如实保留。

## 边界与状态

- 治理记录只覆盖人工校正的五条储能案例；未命中的关系只报告"本次权威查询未记录"，不声称语料中不存在，不编造替代/借鉴/继承关系。
- 不把 accepted 机械升级为 confirmed 或 S2，不自动声称达到 C1。
- **待完成**：两组 50 题正式运行需调用在线模型（作答 API），由用户在本机执行；人评分由用户完成。本仓库交付可运行实现、小批验证结果、空评分表与统计脚本；评分完成后运行 summarize_results.py 即得对比表。
